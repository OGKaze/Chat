# Chat
# 🖥️ RealTime Chat — Backend

Серверная часть чата на **ASP.NET Core 8** с использованием **SignalR** для обмена сообщениями в реальном времени.

## 📦 Стек

| Технология     | Версия | Назначение                         |
| -------------- | ------ | ---------------------------------- |
| ASP.NET Core   | 8.0    | Веб-фреймворк                      |
| SignalR        | —      | Двусторонняя связь через WebSocket |
| C#             | 12     | Язык разработки                    |

## ⚙️ Архитектура

Проект построен по модульному принципу и включает:

- **Hubs** — точка входа SignalR, управляет подключениями и рассылкой сообщений.
- **Controllers** — REST API для вспомогательных операций (получение истории, информация о пользователях и т.д.).
- **Services / Dependencies** — внедрение зависимостей (DI), бизнес-логика, сервисы для работы с данными.
